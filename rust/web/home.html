Pick an endpoint

Everything under /api/v3 is public — start there.

GET /api/v3/categories Categories & subcategories
GET /api/v3/weapons Weapons with tier, item power and icon
GET /api/v3/armors Armor pieces
GET /api/v3/accessories Capes, bags and mounts
GET /api/v3/consumables Food and potions
GET /api/v3/spells/weapon/{id} Spells grouped by slot
GET /api/v3/weapon-stats/weapon/{id} Stats grouped by enchantment
GET /api/v3/armor-stats/armor/{id} Armor stats by enchantment
GET /api/v3/accessory-stats/accessory/{id} Accessory stats by enchantment
GET /api/v3/consumable-stats/consumable/{id} Consumable stats by enchantment
GET /api/v3/consumable-craftings/consumable/{id} Crafting recipes and requirements

Older response shapes live under /api/v1 and /api/v2. The Weaponry app uses /api/weaponry for market prices, search and version checks.

Try it in your terminal

Grab every Tier 8 weapon in one request — no header, no token.

Terminal 
$ curl https://api.openalbion.com/api/v3/weapons?tier=8

Built to stay free

A community project with no paywalls, no keys and no lock-in.

No keys, no catch

Every public endpoint is open to everyone. A fair-use limit of 60 requests per minute per IP keeps the service stable for all.

Open source, MIT

The whole project lives on GitHub — the API, the data pipeline and the Rust rewrite. Fork it, learn from it, improve it.

Self-host in minutes

The Rust API is one binary with the dataset as plain JSON files — no database, no infrastructure. Or deploy it to Cloudflare Workers.

Complete, fresh data

Weapons, armors, accessories, consumables, spells, stats and crafting recipes — collected from the Albion Online Wiki and kept up to date.
